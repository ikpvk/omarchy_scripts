# Omarchy scripts

Kris's scripts and config for their Omarchy machine. Each folder has its own README.

| Folder | What it does |
|---|---|
| [`theme-cleanup/`](theme-cleanup/) | Deletes the unwanted stock Omarchy themes that `omarchy update` reinstalls |
| [`keybindings/`](keybindings/) | A copy of Kris's custom Hyprland keybindings, listed with what each one does |
| [`shell/`](shell/) | A copy of Kris's Omarchy shell settings: bar layout, widgets and idle timers |

Changes to the machine are logged in the second_brain vault, in `system/changelog/`.
